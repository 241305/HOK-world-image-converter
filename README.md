# 王者世界相册图片转换工具

《王者荣耀世界》（NGR）游戏相册 `GameAlbum` 目录下 APD / APT 私有格式图片的转换与替换工具。

游戏相册内的截图是私有格式（APD/APT），无法直接用图片查看器打开。本工具基于对游戏格式的逆向分析，实现 APD/APT 与常见图片格式（PNG/JPG）的双向转换，并支持**无损替换**游戏相册内原有 APD 的图片内容（头部字段、分享码、结构保持不变），让游戏能够正常识别。

## 功能

| 功能          | 说明                                           |
| ----------- | -------------------------------------------- |
| ① APD → JPG | 解包 APD 主图，输出 JPG（可同时输出 PNG）                  |
| ② APD → PNG | 解包 APD 主图，输出 PNG                             |
| ③ PNG → APT | 图片打包为 APT 缩略图                                |
| ④ APT → PNG | 解包 APT 缩略图                                   |
| ⑤ 图片 → APD | 图片打包为可识别的 APD（需账号 ID，推荐用原生截图作模板）           |
| ⑥ 替换 APD 图片 | 用游戏原生 APD 作模板，只替换主图内容，其余字段保留               |

> ①②③④⑤ 均支持直接把文件拖进参数区自动转换，无需点"开始转换"选文件。

### 常用参数

* **账号 ID**：APD 文件名的数字段，打包时建议填写（留空自动写 0；勾选模板时自动读取模板账号，输入框置灰无效）
* **图片质量**：打包为 APD 时的 JPG 压缩质量（1–100，默认 100 无损）
* **使用游戏原生截图 APD 作模板**：复用游戏原生截图的头部信息（真实分享码/昵称/账号/地图/JSON），只替换图片，最稳
* **同时生成 APT 缩略图**：打包 APD 时同步生成同名 APT
* **同步转换到游戏相册**：打包完成后自动复制 APD/APT 到游戏相册目录（需重启游戏生效）
* **仅转换到游戏相册（不在原路径输出）**：配合"同步转换"使用，不污染原图片目录
* **使用原文件名**：生成的 APD/APT 用原图片文件名命名（可能影响游戏识别，谨慎开启）
* **保留备份**：替换 APD 时自动备份原文件到"替换备份"文件夹（默认开启）

## 使用说明

1. **游戏相册路径**：`C:\Users\<用户名>\AppData\Local\NGR\Saved\GameAlbum`（程序可自动定位；左上角「游戏相册」按钮可直接打开）
2. **解包**（功能①②④）：选择 APD/APT 文件（或直接拖入）→ 点击开始转换 → 输出到源文件目录的「转换输出」子文件夹
3. **打包 / 替换**（功能⑤⑥）：
   * 建议先**进入游戏截一张图**，用这张原生 APD 作为模板（勾选「使用游戏原生截图 APD 作模板」并选择它）
   * 家园拍照型截图必须携带真实分享码，使用模板打包可自动复用，避免游戏点开卡死
   * 不使用模板时，需填写账号 ID 并注意尾部缩略图选项（保持关闭即可正常识别）

> 详情请参考程序内置的「使用说明」窗口。

## 构建（可选）

仅需 EXE 的普通用户直接下载 Release 即可，无需自行构建。

```
pyinstaller --onefile --windowed --name "王者世界相册图片转换工具" \
  --icon icon.ico --add-data "icon.ico;." GameAlbum转换工具.py
```

* 需要 Python 3.x 与 `Pillow`、`pyinstaller`
* 产物位于 `dist/` 目录
